# here-core's shared files: what tools/sync.py copies into a city repo.
#   always  <path>   copied into every city
#   present <glob>   copied only where the city already has that file (a new shared script is copied in by hand once)
#   styles  <path>   copied with the city's own --v-* hue runs kept (light, dark, system-dark)
#   never   <glob>   a city's own file, even where a line above matches it
# A city opts out of more in its own .core-keep (see README.md).

styles  site/styles.css

never   scripts/sources.mjs
